# Catálogo de atacado (site inteiro)

Mode: operate

## Direction contract

FORM: pinned by the client's reference (mobile e-commerce claro, preto e branco); concept roll skipped because a brief-pinned decision beats the roll. Seed reference seed:07b6b4eec05e7200 not used.

WORLD (type, palette, density, signature move only):
- Palette: paper white ground, near-black ink for text and primary buttons, warm stone backdrops behind product photos, hairline warm grays. The JM gold (from the logo flare) is reserved for one job: pairs already in the order. Red only for "esgotado".
- Type: one variable grotesk with a width axis (Archivo). Heavy uppercase for headings, condensed width for codes, sizes and counts (echoing the condensed caps of the JM logo), tabular numerals for every quantity and price.
- Density: two-column product grid on the phone, generous photo, tight data under it.
- Surfaces separate by tone (paper / mist / white), not by borders; a border or ring only marks state (gold = in the order, ink = selected/focus). Client asked for fewer borders (nov/2026).
- Signature move: "grade viva". Every product card carries its line's numeração cells as its size ledger (four for feminina/masculina/infantil, two for juvenil); before an order they show the grade's composition (×2 ×4 ×4 ×2); adding grades fills them in gold with the pairs per size. They are read-only: the factory sells closed grades only, never pair by pair. The order is visible on the shelf, not only in the bag.

SHELL:
- Phone: top bar (logo, search), fixed bottom tabs (Início · Catálogo · Pedido · WhatsApp), mini order strip above the tabs when the order has pairs, order as a bottom sheet with the cores × numeração table.
- Desktop (≥ 900px): top nav; order panel fixed on the right pushing the page (≥ 1100px).

FIRST VIEWPORT (home, phone): full-screen (100svh) edge-to-edge flip-flop video, headline "Chinelos no atacado." on the light sky, one line, black "Ver catálogo" + "Como funciona" link; header transparent over it and solid only after scrolling (client request, nov/2026). Desktop: full-height split, text left, video right.

NON-NEGOTIABLE: no eyebrow labels above headings; drawn SVG icons, no unicode glyph icons; nothing claimed beyond PRODUCT.md evidence (envia para todo o Brasil, fabricação própria de parte dos modelos).
